How NeverStop works?

NeverStop allows you to build custom sequences from segments, where each segment can be fully customized. A unique slideshow will then be generated using your own selected photos.

What can be customized in each segment?

Rhythm

Slideshow and metronome speed. Features dynamic tempo changes across several types, such as linear growth, bumps, and edges.

Image Source

Select local photo folders for your custom slideshow generation.

Coming Soon Automatic tag-based image fetching mode

Visual Effects

Visual effects such as color shift, ripple, and pulse.

Fullscreen Effects

Fullscreen overlays including vignette, spiral, and hypnotic rings.

Audio Generators

Built-in generators for noise, binaural beats, and isochronic tones.

Audio Player

Dedicated player allowing you to load and play custom MP3 files during your sessions.

Captions

BETA

Support for triggering custom MP3 tracks synchronized with any chosen caption.

Haptics

Coming Soon

Vibration and haptic feedback support for immersive sessions.

Duration

Precise configuration of time duration for each individual segment.

Future Vision

In the future, linear session planning will be replaced by a branching tree system with randomized path selection. This will allow for creating dynamic, ever-changing sessions that never get repetitive.
